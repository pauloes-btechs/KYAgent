Screen a wallet

Paste one address per line, up to 50. Each is checked for an exact match against every digital currency address OFAC publishes on the SDN list.

Examples
How this maps to KYAgent. In production this is the sanctions stage's exact-match step: find({ "wallets.address": … }) on a B-tree index in MongoDB Atlas. It is an invariant, so a hit always blocks, regardless of any learned rule.

Screen a counterparty name

Fuzzy and phonetic matching across every SDN name and alias, so transliterations and look-alike spellings still surface.

Examples
Why names never auto-block. Names are not unique, so a name match is evidence for an analyst: the case goes to REVIEW with scored matches attached. In KYAgent this runs as $search with standard and phonetic analyzers on the sanctions_search Atlas Search index.
